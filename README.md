# FOX Virtual Universe Music — Community

مستودع المجتمع العام لمشاركة الأفكار الموسيقية والتعاون بين الكتّاب والملحنين والمغنين والموزعين والمطورين.

هذا المستودع **ليس مستودع الإنتاج الرسمي**. لا ترفع إليه ملفات الماستر، بيانات خاصة، مفاتيح API، أو مواد لا تملك حق مشاركتها.

## المسار

```text
مشاركة عامة
→ مراجعة الحقوق والاعتمادات
→ مراجعة المحتوى
→ Pull Request
→ اعتماد الإدارة
→ نقل انتقائي إلى المستودع الخاص
→ إصدار رسمي
```

المستودع الخاص للإنتاج:
[virtual-universe-music](https://github.com/mhmdalhndsh597-alt/virtual-universe-music)

## ماذا يمكن مشاركة؟

- كلمات أو أفكار أصلية.
- ألحان خام.
- إيقاعات وتوزيعات أصلية.
- عروض صوتية منخفضة الجودة عند امتلاك الإذن.
- أدوات تطوير وتوثيق غير حساسة.
- اقتراحات وتحسينات للمنصة.

ضع المحتوى في المسار المناسب:

- `community_submissions/written_lyrics/`
- `community_submissions/raw_melodies/`
- `community_submissions/music_beats/`
- `community_submissions/vocal_demos/`
- `community_submissions/developer_tools/`

## المشاركة

راجع [CONTRIBUTING.md](CONTRIBUTING.md)، ثم استخدم نموذج المساهمة من تبويب Issues. كل مشاركة تحتاج وصفًا ومصدرًا واضحًا وإقرارًا بالحقوق أو الترخيص.

لطلب شراء أو ترخيص أو توزيع أو تعاون تجاري، استخدم نموذج **Order or distribution request**. النموذج عام للمراجعة اليدوية فقط؛ لا يجمع بيانات دفع ولا يؤكد عملية شراء.

لا يعني فتح Pull Request قبول العمل أو إدخاله في إصدار رسمي. الاعتماد النهائي يتم يدويًا في المستودع الخاص.

## بوابة المجتمع

بوابة المجتمع العامة موجودة في `docs/` ويمكن نشرها عبر GitHub Pages. لا تحتوي على ملفات إنتاج خاصة، وتوجه المشاركين إلى النماذج العامة فقط.

## تنبيه الحقوق

المراجعة الآلية لا تثبت الملكية القانونية. لا ترفع مواد تجارية أو عينات أو تسجيلات أشخاص آخرين دون تفويض مناسب. لا تحفظ كلمات مرور أو Tokens أو بيانات دفع في هذا المستودع.
